キー取得マニュアル

領収書仕訳システムで使用するAPIキーの取得手順

はじめに

このマニュアルでは、領収書仕訳システムで領収書の文字認識（OCR）を行うために必要な Google Cloud Vision APIのAPIキーを取得する手順を説明します。

料金について：月1,000枚まで無料で利用できます。それ以降も1枚あたり約0.2円と非常に低コストです。

使用量 料金
月0〜1,000枚 無料
月1,001枚以降 約$1.50/1,000枚（約0.2円/枚）

準備するもの

  • Googleアカウント（Gmail等）
  • クレジットカードまたはデビットカード（本人確認用。無料枠内では課金されません）

手順1：Google Cloud Consoleにアクセス

1

Google Cloud Consoleを開く

以下のリンクをクリックしてGoogle Cloud Consoleにアクセスします。

Google Cloud Console を開く
2

Googleアカウントでログイン

お持ちのGoogleアカウントでログインしてください。

初めて利用する場合は、利用規約への同意が必要です。

手順2：新しいプロジェクトを作成

1

プロジェクト選択メニューを開く

画面上部の「プロジェクトを選択」または現在のプロジェクト名をクリックします。

2

「新しいプロジェクト」をクリック

ポップアップ画面の右上にある「新しいプロジェクト」ボタンをクリックします。

3

プロジェクト名を入力

任意のプロジェクト名を入力します。例：

receipt-ocr

「作成」ボタンをクリックしてプロジェクトを作成します。

4

作成したプロジェクトを選択

プロジェクトが作成されたら、そのプロジェクトを選択して切り替えます。

手順3：Cloud Vision APIを有効化

1

APIライブラリを開く

左側メニューから「APIとサービス」→「ライブラリ」を選択します。

または以下のリンクから直接アクセスできます：

Cloud Vision API ページを開く
2

Cloud Vision APIを検索

検索ボックスに「Cloud Vision API」と入力して検索します。

3

「有効にする」をクリック

Cloud Vision APIのページで「有効にする」ボタンをクリックします。

初回は課金アカウントの設定が必要な場合があります。クレジットカード情報を入力しても、無料枠内では課金されません。

手順4：APIキーを作成

1

認証情報ページを開く

左側メニューから「APIとサービス」→「認証情報」を選択します。

認証情報ページを開く
2

「認証情報を作成」をクリック

画面上部の「+ 認証情報を作成」ボタンをクリックし、「APIキー」を選択します。

3

APIキーをコピー

APIキーが生成されます。このキーをコピーしてください。

AIza○○○○○○○○○○○○○○○○○○○○○○○○○

重要：このAPIキーは他人に見せないでください。悪用される可能性があります。

手順5：領収書仕訳システムにAPIキーを設定

1

領収書仕訳システムにログイン

領収書仕訳システムにGoogleアカウントでログインします。

領収書仕訳システムを開く
2

設定画面を開く

画面右上の「⚙️ 設定」ボタンをクリックします。

3

APIキーを貼り付けて保存

コピーしたAPIキーを入力欄に貼り付け、「保存」ボタンをクリックします。

「APIキーを保存しました」と表示されれば設定完了です！

トラブルシューティング

「APIキーが無効です」と表示される場合

  • Cloud Vision APIが有効になっているか確認してください
  • APIキーが正しくコピーされているか確認してください
  • プロジェクトに課金アカウントが設定されているか確認してください

課金アカウントの設定方法

Google Cloud Consoleの「お支払い」メニューから課金アカウントを作成し、プロジェクトにリンクしてください。

お支払い設定を開く

APIキーの制限設定（推奨）

セキュリティを高めるため、APIキーに制限を設定することをお勧めします。

1

APIキーの編集画面を開く

認証情報ページで作成したAPIキーをクリックします。

2

API制限を設定

「APIの制限」セクションで「キーを制限」を選択し、「Cloud Vision API」のみを選択します。

これにより、このキーはCloud Vision API以外には使用できなくなります。
